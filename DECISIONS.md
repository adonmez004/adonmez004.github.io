# Decisions

The standing decisions behind `inspector.js`, by area. They are the contract a refactor must keep: a change that alters one of these is a product change and needs Alper's call, not a code-quality one. CHANGELOG.md tells when each landed; this file tells what stands today and why. Items marked REFUSED were asked for by outside reviews (six Codex passes between v0.1.17 and v0.1.71) and declined every time; do not re-add them unprompted.

## Scope

- The inspector explains a solution, it does not export one. No copy, download or extract features (README, v0.1.1).
- One file, `inspector.js`, served at the demo site's root and loaded by every solution with one `<script defer>`. Zero runtime dependencies, nothing fetched but the page's own sources. The source may live in several files, the built output is that one file and is never edited by hand.
- The file's first line is `// inspector.js vX.Y.Z`, the host element carries `data-version`, the copyright line closes the file (v0.1.21). The version is shown nowhere on screen (v0.1.4).
- Every batch that reaches the copy page bumps the PATCH; minor and major bumps are Alper's call.

## The browser suites and v0.2.1 (2026-10-16)

- The suites were written against v0.1's chrome (the pill, the tabs, the size bar, the theme and undo buttons), and the v0.2.0 release went out verified by per-feature headless scripts only: a full run that night failed all 62, nearly every one at the dead `.fab` click (Alper: "tüm suit'lerden test yaptın mı", then "bence suit'lere de bakabilirsin çünkü yeni bir çok özellik ekledik belki suit'ler onlara göre değildir"). The port (four parallel batches of 15, the same night) keeps the suites' observational style and their v0.1.82 numbers where the behaviour stands, rewrites the ones whose feature changed shape (the quick view for the picker, the resize box for the bar, Clear all for the resets, the head-click fold, the rail strip on phones, test-visual's seven states), and deletes only two whose feature is gone (the theme toggle, the head's version label). `lib/browser.mjs`'s `openBox` is the one door to the box: the lens armed, a page element clicked 12px inside its corner (2px missed the QR card's 20px radius and scoped to main), Show All pressed; `park()` moves the box to the left edge because the size view opens over a right-side element's handle at 1280px (a mouse drag then lands on the box: the suites' first null results; a known v0.2 fact, still open as design). `.panel`, `.head`, `.close` match the second box too, so the suites say `#panel`.
- What the port found, fixed in v0.2.1: (1) a 3000-element page paid the layout of the OLD rows again inside every HTML rebuild, because `tree()`'s `rendered()` reads force a layout while the stale 6000 rows still stand; `load()` empties the view first (the open bucket 15.5 s → 11.6 s with two rebuilds in it, loadHtml 4.7 s → 2.4 s, v0.1.82: 2.1 s); the `:has()` row selectors (`.row:not(:has(.caret))`, `.d:has(> .src)`, `.d:has(> .why)`) became classes, a smaller cost but one that grows with every row; a `content-visibility: auto` on the rows would cut the panel's own layout (2.2 s → 0.5 s measured) at the price of the view's width following the visible rows, parked. (2) An Escape-cancelled edit re-renders the CSS view through `queueLoad`, and the focus the editor had put back sat on a detached row, so the next Escape fell to the page and never closed the box (v0124 step 5); `render()` finds the declaration whose row holds the focus and refocuses its value on the new rows. (3) The Tools shield captured `pointermove` at the window and stopped it whenever the pointer was over the page, so a sheet pull or a head drag whose moves left the box while a lens stood lost them (sheet2: 272 instead of 422); the shield asks the host `busy()` (a running `gesture()`) and stands aside. (4) The hold line's wording, caught by test-block: an `!important` width lost the word and read `held by  !important`, the parent's name lost its colon, the grid track read its value twice.
- Three suites added after the release (2026-10-16 morning, Alper: "suit'lere tekrar bak, eklenecek bir şey varsa, yeni bir suite vs ekle"), for the v0.2 features no suite read: `test-sources` (the source links under the `computed` head on Show Initials / Show Computed: All lit at rest, a click narrows to one source with its note, a second click or a new scope or block widens, Initials drops the struck rows while narrowed and Computed keeps its struck browser rows; the currentcolor property as ONE unstruck row per colour property with `from color: rgb(…)` and its `!` line; unicode-bidi's `normal` initial under the browser's `isolate`), `test-sizelinks` (Show Size's `All · Element · Parent · Grandparent · … · Body · Viewport` links, the Element box's content / rendered content / space / with margin lines, the Viewport entry as the window's size, a block child's `the children's boxes together`) and `test-v021` (the three fixes: the Escape-cancelled edit keeping the focus in the box so the next Escape closes it, a head drag with the lens armed landing where the plain drag lands, the hold line's `!important` in the label and out of the note, plus the resized element's dimension lines and the signed difference). `test-v021` was run against the v0.2.0 build too and fails all three there (the focus on body and the box standing, the armed box not moving, the label without `!important`), so it reads the fixes and not the test. A full `run-all` with them: see the count in CHANGELOG's v0.2.1 entry. Noted while writing them: Show Size's body line wears the kin word `ancestor 4` under its `body W × Hpx` head while its link reads `Body`; left as is for Alper's call.

## Extensions and foreign nodes

- Nodes that browser extensions add are left out of the HTML tab, the CSS tab and the picker: the page's own HTML source is fetched once; a top-level node absent from it that has an id, a hyphenated name or a shadow root counts as foreign (`<style>`, `<link>`, `<script>` never do); a few extensions are known by name for when the source cannot be read (v0.1.28, v0.1.37). Ad-blocker cosmetic sheets (≥10 hide-only rules with filter-list selectors, not in the source) are dropped (v0.1.27, v0.1.37). `data-fm-inspector-ignore` marks a page's own helper node (v0.1.71); set or removed while the panel is open, it is a page change: the pick, the resize target and the inline group go with the mark, the rows return when it goes (v0.1.76).
- ACCEPTED trade-off: an id'd modal or custom element the page's own script adds at runtime is hidden too. REFUSED: removing the filter (v0.1.71).

## Lifecycle
